# PDF电子发票批量合并打印工具

这是一个高效的PDF电子发票批量合并打印工具，帮助用户节省纸张、提高效率并保护环境。

## 功能特点

### 📄 节省纸张
- 多张发票打印在同一张A4纸上，最多节省75%的纸张
- 支持1张/页、2张/页、4张/页的打印布局

### ⚡ 提高效率
- 支持拖拽PDF发票文件批量上传
- 一次操作完成多张发票的合并和打印
- 自动计算并显示节省的纸张数量和多造的氧气量

### 🌱 保护环境
- 合并3000次，就少砍一颗大树
- 为人类多造4公斤氧气，为环保事业贡献力量

### 🎨 用户友好
- 现代化的响应式界面，支持PC端和移动端
- 实时文件列表管理，可随时删除不需要的文件
- 合并过程中的加载状态和进度显示
- 合并后提供PDF预览功能，确保输出效果

### 🔧 技术优势
- 纯前端实现，无需后端服务器
- 完善的错误处理和异常捕获
- 智能内存管理，防止浏览器崩溃
- 支持大文件和多文件处理

## 如何使用

### 步骤一：打开应用
- 直接在浏览器中打开 `index.html` 文件
- 或通过本地服务器访问（推荐使用 `python -m http.server 8080` 启动服务器）

### 步骤二：上传发票
- **方式一**：点击"选择发票"按钮，在弹出的文件选择对话框中选择PDF文件
- **方式二**：直接将PDF文件拖拽到浏览器窗口中

### 步骤三：管理文件
- 在文件列表中查看已上传的文件
- 点击文件右侧的"删除"按钮移除不需要的文件
- 点击"清空列表"按钮移除所有已上传的文件

### 步骤四：设置打印选项
- **每页发票数量**：选择1张/页、2张/页或4张/页
- **页面方向**：选择纵向或横向（选择4张/页时会自动切换为横向）

### 步骤五：合并预览
- 点击"合并预览"按钮，系统会开始处理上传的PDF文件
- 处理完成后会自动打开预览窗口，显示合并后的PDF效果

### 步骤六：下载打印
- 在预览窗口中点击"下载PDF"按钮，将合并后的文件下载到本地
- 使用PDF阅读器打开下载的文件并打印

## 技术实现

### 核心技术栈
- **前端框架**：HTML5 + CSS3 + JavaScript
- **UI框架**：Bootstrap 5
- **PDF处理**：pdf-lib 库
- **文件下载**：FileSaver.js 库

### 实现原理
1. **文件上传**：通过HTML5的File API和拖拽API实现文件上传
2. **PDF处理**：使用pdf-lib库加载、合并和操作PDF文件
3. **页面布局**：根据用户选择的每页发票数量和页面方向计算布局
4. **预览功能**：使用iframe嵌入PDF文件进行预览
5. **文件下载**：使用FileSaver.js库实现文件下载功能

### 性能优化
- **文件限制**：单个文件大小限制为10MB，总文件大小限制为50MB
- **数量限制**：最多支持100个文件，最多处理1000页
- **内存管理**：使用URL.revokeObjectURL释放预览资源
- **错误处理**：完善的try-catch捕获和用户友好的错误提示

## 注意事项

### 系统要求
- 现代浏览器：Chrome 60+、Firefox 55+、Safari 12+、Edge 79+
- 推荐使用PC端浏览器，手机端上传PDF文件较为困难

### 支持的文件格式
- 仅支持PDF格式的文件
- 支持标准的PDF文件，包括电子发票、普通PDF文档等

### 性能提示
- 对于大量文件或大文件的处理，可能需要较长时间
- 处理过程中请保持浏览器窗口打开，不要刷新页面
- 如果遇到内存不足的提示，请减少上传的文件数量或大小

### 打印建议
- 使用高质量的打印设置以获得最佳效果
- 打印后可以使用虚线作为参考进行裁剪
- 建议使用双面打印进一步节省纸张

## 环境搭建

### 方法一：直接打开
1. 下载项目文件到本地
2. 直接在浏览器中打开 `index.html` 文件

### 方法二：使用本地服务器
1. 下载项目文件到本地
2. 打开命令行工具，进入项目目录
3. 运行以下命令启动本地服务器：
   ```bash
   # 使用Python 3
   python -m http.server 8080
   
   # 或使用Python 2
   python -m SimpleHTTPServer 8080
   
   # 或使用Node.js (需要安装http-server包)
   npx http-server -p 8080
   ```
4. 在浏览器中访问 `http://localhost:8080`

## 常见问题

### Q: 上传文件时显示"文件大小超过限制"怎么办？
A: 单个PDF文件大小不能超过10MB，总文件大小不能超过50MB。请尝试分批处理文件。

### Q: 合并过程中浏览器崩溃了怎么办？
A: 这可能是由于处理的文件过多或过大导致的内存溢出。请减少上传的文件数量，或选择更少的每页发票数量。

### Q: 合并后的PDF文件中的发票显示不全怎么办？
A: 系统会自动调整发票大小以适应页面布局，但如果发票内容特别密集，可能会影响可读性。建议选择合适的每页发票数量。

### Q: 打印后裁剪不方便怎么办？
A: 系统在PDF中添加了虚线作为裁剪参考，请根据这些虚线进行裁剪。
